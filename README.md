# Grade-Finder
Find your each subjects' grades (Grade points) using this tool, Made for SCMS Pune LMS.

How to use: 
Just download the HTML file, and run it, then you have copy the marks of the whole batch from the LMS of your college, and paste in the space provide then select your name, and boom! there is your grade out of all the students you have in your course.

Note: I have made this using the rules of SIU and SCMS Pune, the rules might change for your college check once before using.

Imp: This is not an official tool by any university, this is a private project created to estimate the grades. the result it shows is not final. This tool can make mistake, please double check the responses.
